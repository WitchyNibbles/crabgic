RESIDUAL — what this batch did NOT close, pinned in prose and in the test file
===============================================================================
The gate binds the WRITER, not the committed artifact. Nothing reads
`live-verdicts.json`'s own `source` field, so a hand-edit of that string is still
undetectable — which is precisely what commit `29b3c46` did, and how the label
came to claim a live provenance months before any green `@live` run existed.

What changed: no CODE PATH can mint the label any more. The only caller of
`writeLiveVerdicts` must present a `CanaryResult`, and a fabricated one is
refused at runtime as well as by the type system.

What did not change, and should not be oversold: the criterion's provenance
evidence is still the green run, the moved mtime and the clean `git diff`
recorded at `docs/evidence/phase-06/closeout/closeout-live-batch.txt` §4 — never
the `source` string. Deriving provenance from the artifact itself would require
the file to carry something a fake cannot reproduce; that is a larger design
change than the defect record proposes, and this batch did not attempt it. The
residual is restated at the head of
`packages/engine-claude/src/live/live-verdicts-provenance.test.ts` so a reader
meets it at the point of edit.
