  unconditional `return { halted: false };`. This is the probe that decides

  vacuous. THREE tests reddened —

      × a material signal halts an in-flight run: run -> blocked, one

      × an already-halted run cannot be halted again —

        polls, halts the run via 11's material_amendment stop condition
        before final_verifying                               [cli seam e2e]

  and BOTH does-not-halt controls stayed GREEN, which is exactly what makes them
  controls rather than restatements: an unconditional no-op is the world the
  controls describe, so they must survive it.

  M4 — CHANGE THE KIND. `kind: "material_amendment"` -> `kind: "expanded_authority"`.
  The criterion names the kind, so a bearer that merely asserted "some decision
  was journaled" would stay green here — the `toThrow(ConnectorError)` failure
  shape. TWO tests reddened, and they are precisely the two that pin the
  rationale string:

      × a material signal halts an in-flight run: ...         [supervisor unit]
      × a seeded mid-run tracked-field edit, ...              [cli seam e2e]

  Note the M4 count (2) is strictly smaller than M3's (3): the no-resurrect test
  asserts the transition and the decision COUNT but not the kind, so it survives
  a kind swap. That difference is the measurement — the two probes are not
  redundant.

  M1/M2 double as the seam probes. Under M1 (the poll deleted) the cli e2e
  reddens at `second.revisionPoll?.signal?.material`, which proves the e2e
  actually consumes 18's producer rather than a hand-built stand-in inside the

MATCHED-STRING HYGIENE, AUDITED AGAINST THE OPPOSITE OUTCOME

  * `"blocked"` is asserted only as the exact value of `RunRecord.runState`, a
    closed 11-member enum field — never as a substring search. The three other
    "blocked" vocabularies this seam touches (17's
    `MilestoneSyncOutcome.status: "blocked"`, `JiraWorkflowStage` "blocked", and
    gate-verdict prose) therefore cannot satisfy it. Every milestone cycle in the
    e2e additionally asserts `outcome.status === "planned"`, so the lint-blocked
    arm cannot stand in unnoticed.
  * `stop condition "material_amendment"` — the controls assert the decision list
    for their runId has LENGTH 0, the strongest form of "does not contain it".
    The non-halted outcome is `{halted:false}` with no `record` and no reason
    string, asserted with an exact `toEqual`, so it is disjoint by SHAPE from the
    halted outcome, not merely by string.

#!/usr/bin/env python3
"""Notation-aware inbound-citation census for docs/evidence/phase-21/README.md.

REPLACES the narrow instrument used on 2026-08-06, which published "cited
nowhere" as a measurement and was WRONG. Two defects in the old tool, both of
which return a SMALLER answer with no error:

  1. it matched per LINE, so a reference whose filename and line number sit on
     different source lines could never match (prose wraps; the regex did not);
  2. its proximity window was narrow, so a prose "line NN" more than a few
     dozen characters from the nearest filename mention fell outside it.

The real reference it missed — roadmap/21-connector-evidence-integration.md:126,
"...heading is still at line 237..." — is 218 chars from the nearest
`phase-21/README` mention with 2 newlines in between. Hence: JOIN the document
first, then scan a +/-600-char window around every mention, for BOTH notations.
Deliberately over-inclusive: if an over-inclusive set misses your edit range, the
true set certainly does.
"""

import re
import subprocess
import sys

TARGET_HINTS = ["phase-21/README", "phase-21/README.md"]
WINDOW = 600

# Files EXCLUDED from the referrer set, with the reason stated in the output so
# the exclusion is visible rather than hidden. These are this census's own
# capture: they quote line numbers while REPORTING on citations, so a match
# inside them is the tool reading its own output, not a reference that could be
# stranded by an edit to the README. Everything else in the repo stays in scope.
SELF_CAPTURE = {
    "docs/evidence/phase-21/halt-wiring-probes-batchB.txt",
    "docs/evidence/phase-18/milestone-poll-probe-batchB.txt",
}

EXPLICIT = re.compile(r"phase-21/README\.md:(\d+)(?:-(\d+))?")
# prose notations: "at line 237", "line 237", "lines 398-399", "(line 113)"
PROSE = re.compile(r"\blines?\s+(\d+)(?:\s*-\s*(\d+))?\b", re.I)


def repo_files():
    out = subprocess.run(
        ["git", "grep", "-l", "phase-21/README", "--", "."],
        capture_output=True, text=True, check=False,
    ).stdout.split("\n")
    return [f for f in out if f and "/dist/" not in f]


def census(files, self_path):
    hits = []
    for f in files:
        try:
            raw = open(f, encoding="utf-8").read()
        except (OSError, UnicodeDecodeError):
            continue
        # line map for reporting, then JOINED text for matching
        lines = raw.split("\n")
        starts, pos = [], 0
        for ln in lines:
            starts.append(pos)
            pos += len(ln) + 1
        joined = raw.replace("\n", " ")

        def lineno(off):
            lo, hi = 0, len(starts) - 1
            while lo < hi:
                mid = (lo + hi + 1) // 2
                if starts[mid] <= off:
                    lo = mid
                else:
                    hi = mid - 1
            return lo + 1

        for m in re.finditer(r"phase-21/README(?:\.md)?", joined):
            lo = max(0, m.start() - WINDOW)
            hi = min(len(joined), m.end() + WINDOW)
            window = joined[lo:hi]
            for em in EXPLICIT.finditer(window):
                hits.append((f, lineno(lo + em.start()), "explicit", em.group(0)))
            for pm in PROSE.finditer(window):
                hits.append((f, lineno(lo + pm.start()), "prose", pm.group(0)))
    # dedupe
    seen, out = set(), []
    for h in hits:
        if h in seen:
            continue
        seen.add(h)
        out.append(h)
    return sorted(out)


def main():
    all_files = repo_files()
    files = [f for f in all_files if f not in SELF_CAPTURE]
    skipped = [f for f in all_files if f in SELF_CAPTURE]
    self_path = "docs/evidence/phase-21/README.md"
    hits = census(files, self_path)
    print(f"census: scanned {len(files)} file(s) mentioning phase-21/README, window +/-{WINDOW} chars, JOINED text")
    if skipped:
        print("  EXCLUDED as this census's own capture (they quote line numbers while")
        print("  REPORTING on citations; a match inside them is the tool reading its own")
        print("  output, not a reference an edit to the README could strand):")
        for f in skipped:
            print(f"    - {f}")
    external = [h for h in hits if h[0] != self_path]
    internal = [h for h in hits if h[0] == self_path]
    print(f"\nEXTERNAL referrers carrying a line number ({len(external)}):")
    for f, ln, kind, txt in external:
        print(f"  {f}:{ln}  [{kind}]  {txt!r}")
    print(f"\nINTERNAL (self-references inside {self_path}) ({len(internal)}):")
    for f, ln, kind, txt in internal:
        print(f"  {f}:{ln}  [{kind}]  {txt!r}")
    return external, internal

    if len(sys.argv) > 1 and sys.argv[1] == "--mutation-test":
