§0. WHAT WAS BROKEN, AND WHAT THIS PROBE HAS TO SHOW
----------------------------------------------------
Adversarial review of PR #94 (attack G, 2026-08-05) mutated the tenant scenario's own closure —

    passed: result.ok === false   ->   passed: true

— and both packages stayed green at 83 files / 660 tests. The gate added by PR #94 is a faithful
reporter of whatever the scenario concludes, so its refusal-detecting power rode entirely on the
scenario's integrity, and nothing per-push pinned that direction. The three scenarios also had no
seam: org 999 vs allowlist ["7"], the real adapter and the real guard were hardcoded inside the
closures, so no test could construct a world in which a scenario OUGHT to fail.

The fix gives each scenario a factory whose every override defaults to the real production
dependency, and rebuilds the module-level constants as those factories' zero-argument products.
Six reverse probes (RP-T1/T2, RP-F1/F2, RP-R1/R2) assert the fail-world verdict.

This transcript must show four things:
  (a) each scenario's verdict is now DERIVED — a constant `true` dies                    -> M1,M2',M3
  (b) each verdict's individual conjuncts are pinned, not just the whole                 -> M2a',M2b',M3a,M3b
  (c) adding these checks did NOT un-pin the neighbouring gate-layer coverage            -> M4
  (d) exactly where the DEFAULT-argument residual begins and ends — measured, not argued -> M5a,M5b

§5. THE DEFAULT-ARGUMENT RESIDUAL — measured, and narrower than the gate layer's equivalent
--------------------------------------------------------------------------------------------
Injected-path tests cannot prove the DEFAULT arguments stay coupled to the real dependencies. This
probe measures exactly where that residual starts:

  rewire the default to an ALWAYS-ACCEPT stub   -> dies on the pre-existing pass-world it.each row
  rewire the default to an ALWAYS-REFUSE stub   -> dies on RP-T2                    (M5a, MEASURED)
  rewire the default to a FAITHFUL FROZEN COPY  -> NOTHING REDDENS                  (M5b, MEASURED)

M5a is the strengthening over the defect record's minimal remedy, which pinned only the injected
path: RP-T2 drives the REAL default doctor into its accept branch, so the two crude rewires are both
per-push-detectable. M5b is the honest remainder. A behaviourally faithful frozen copy decouples the
scenario from the production doctor without changing any observable verdict, and only re-running an
M4-style deletion probe at a later tree detects it. Its all-green result is the measurement, not a
failure of the probe.

Two things this transcript will NOT let a reader over-read:
  * No equivalent narrowing exists for the `adapterFactory` or `guard` defaults. There is no RP-F/RP-R
    analogue of RP-T2, and M4's deletion probe does not reach them. Their residual is wider.
  * The treatment for all three is the same as PR #94 set for the gate layer: the in-file ⚠️ RESIDUAL
    comment above the factories in fault-injection-matrix.ts, plus this transcript as a
    POINT-IN-TIME coupling proof. Neither is a per-push pin, and neither is described as one.
