# The first completed autonomous run

**2026-08-16, run `04a0bf70-7835-4c49-af24-df70b7759740`.** The full lifecycle,
end to end, with **no human anywhere in it**.

```
draft → awaiting_approval → ready → running
      → verifying → integrating → final_verifying → published_local
```

**Worker:** 31 turns, **$1.96**, ~6 minutes. **Integrated commit:** `df730f6b`,
23 insertions / 12 deletions, confined to its one owned path.

## What "no human in it" means, precisely

Every gate in that sequence was decided by code reading its own records:

| Step               | Decided by                                                              |
| ------------------ | ----------------------------------------------------------------------- |
| approval           | the standing `EnvelopePolicy` — `policy_contained`, no prompt, no token |
| criteria sealing   | 3 acceptance-criteria sets hashed at approval                           |
| readiness          | every requirement mapped to a work unit                                 |
| dispatch           | the same policy, re-read rather than cached                             |
| implementation     | an envelope-bounded worker in its own worktree                          |
| collection         | `git add` bounded to the owned paths                                    |
| integration        | merge-tree preflight against the integration tip, CAS-landed            |
| final verification | the composed gate registry firing at `final_verifying`                  |

The operator's only acts were `crabgic run < intake.json` and reading the
journal afterwards.

## What it took to get here

Five defects, none of which any test suite could see, all found by RUNNING the
system rather than reasoning about it. Each is committed separately with its own
measurement:

| #   | Defect                                                        | Consequence                             |
| --- | ------------------------------------------------------------- | --------------------------------------- |
| 1   | parked on routine `rate_limit_event` telemetry                | **no run could ever complete**          |
| 2   | published `outputFormat` schema ≠ enforced schema             | **no worker could ever succeed**        |
| 3   | `schemaViolation` journaled `failed` with no reason           | every diagnosis cost hours              |
| 4   | `$schema` annotation the engine's validator refuses           | run died 1.3 s in, before a worker      |
| 5   | collection refused when the project gitignores `node_modules` | a **succeeded** worker's work discarded |

**Three of the five were hidden by fixtures that encoded the defect.** The park
tests staged their park with an `allowed_warning` payload, so the suite
positively asserted that routine telemetry parks a worker. `FakeEngineAdapter`
emitted a seven-field `WorkerResult` no real worker could produce, and a test
asserted exactly that conformance. A green suite agreeing with a defect is worse
than no suite, because it is evidence pointing the wrong way — the vacuity
pattern `docs/verification-playbook.md` names, in its most expensive form.

Defect 3 is the cheap one and it paid for itself immediately: defect 4 was
diagnosed in two minutes from a daemon log line that named the remedy, where
defect 2 had taken hours of reading branches against a raw transcript.

## What this does NOT demonstrate

Stated plainly, because the run is a milestone and milestones invite
overreach:

- **One work unit, one lens-free stage.** No design panel ran, no SDD documents
  were generated by the system, no four-lens review loop executed, no audit
  stage fired, no documentation stage ran. This exercised
  `intake → approve → dispatch → implement → integrate → publish`, which is the
  spine, not the whole pipeline.
- **The run published work NOBODY VERIFIED**, and the worker self-reported
  `"summary": "test"` after twelve failed `Bash` calls. That is the more
  important half of this result and it has its own record:
  `published-unverified.md`. Read it before citing this page as a success.
- **The worker still cannot run commands.** `docs/evidence/phase-25/first-worker-output.md`
  records the sandbox failing to initialize (`Failed to create bridge sockets`)
  on this host. This run's acceptance criteria demanded tests; none were run.
  A run can now COMPLETE without its work having been VERIFIED, which is a
  weaker guarantee than it looks and the next thing to close.
- **`published_local` is local.** Nothing was pushed anywhere.
- **Convergence is still unmeasured.** One work unit, one attempt, no repair
  round. Ledger Gap 19's residual is untouched by this.
